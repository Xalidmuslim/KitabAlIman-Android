# Книга Имана v0.16

Новый каталог: 79 вручную отобранных точных фрагментов из 54 глав, ссылки ведут к конкретным блокам книги. Семь предыдущих записей сохранены. На этапе сборки проверяется совпадение каждого фрагмента с реальным текстом в `book.json`; при несовпадении сборка останавливается. Заметка: цитаты могут содержать слова учёных и цитируемые тексты внутри книги, не все являются прямой речью Ибн Таймийи.

Карточки домашней навигации уменьшены до 81dp (3D-значки — до 76×65dp), быстрые подборки — до 86dp с количеством глав вместо повторяющегося текста. Голосовая панель в одной тонкой Surface-рамке с одной строкой основных элементов; воспроизведение, пауза, остановка, изменение скорости и настройки RuVoice не удалены.

Сохраняются 131 глава, все сноски, 524 задания, текст, прогресс, поиск, нижняя навигация. Тестировать визуальную компоновку на настоящем Android-телефоне; успешная сборка не доказывает пиксельной точности.
