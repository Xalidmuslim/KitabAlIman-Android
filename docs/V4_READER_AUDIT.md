# Проверка 0.4.0

На основании 131 главы из supplied book.json:
* 130 первых текстовых блоков дублируют название главы с типографическими отличиями. Скрывать только визуально, сохраняя ID, текст и заметки.
* 857 цитат Корана с определяемыми границами в 334 блоках, включая 9:31. Текст делится на видимые фрагменты в Kotlin UI. Выделения и заметки используют исходные смещения внутри каждого блока.
* 9 дополнительных ссылок с неуравновешенными кавычками требуют ручной сверки. Автоматически не приписывать их Корану.
* 242 сноски сохранены с ID и текстом, только уменьшается размер и высота карточек.
* Оглавление уменьшается по отступам, сохраняет порядок 131 главы.
* Движок исходной «Медицины Пророка» и предыдущие версии приложения не изменяются.
* Автоматические тесты не равнозначны полной редакторской сверке PDF.

Патч хранился как base64/gzip во время загрузки GitHub-коннектором. scripts/unpack_v4.py строго проверяет SHA256 перед извлечением читаемого Python-модуля; Actions выполняет Python/Gradle тесты и публикует APK после проверки подписи и ресурсов.
