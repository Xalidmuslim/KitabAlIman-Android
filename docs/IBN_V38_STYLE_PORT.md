# Перенос интерфейса «Болезнь и исцеление», версия v38

Эталон: `IbnKayim_v38_Quiz_Review_30.zip`, файл `Quick/assets/index.html` (HTML/CSS/JavaScript). В нативный Compose перенесены верхняя панель, редакционная бумажная палитра, главный экран с цитатой, прогрессом, статистическими блоками и карточками, а также компактное оглавление с тремя фильтрами состояния.

Отдельное меню внизу, названия пяти вкладок, значки `nav_*` и компоненты нижней навигации **не изменены**. Текущие Reader.kt, FaithStudy.kt, BookData, AppStore, поиск, закладки и история чтения сохранены. В Reader.kt добавлено только оформление разделителя заголовка без нового LazyColumn item.

Не переносить содержимое книги Ибн Каййима; книга, открытая в этом приложении, по-прежнему книга Имана Ибн Таймийи.

Ограничения: версия v38 использует HTML-учёт времени чтения и интервальное повторение, в Android приложении пока используются существующие функции прогресса и проверки усвоения. Это не полное побайтовое совпадение логики. Текущие навигация и данные пользователя приоритетнее.
