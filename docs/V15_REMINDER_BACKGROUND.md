# Книга Имана v0.15.0

Согласованное изображение книжной композиции на светлом фоне встроено в APK напрямую как `drawable-nodpi/iman_quote_v15.webp` (850×425, WEBP). Исходник сохранён в `assets/ui/iman_quote_v15.webp`. Текст расположен слева, книги справа; используется `ContentScale.FillBounds`, чтобы не обрезать рамку изображения при разных пропорциях карточки.

Кнопка «Другая ↻» перенесена в верхнюю строку, чтобы не перекрывать книги. Все семь цитат, источники, переходы в точные главы и блоки сохранены. Не затронуты нижняя навигация, иконки, озвучивание, прогресс, экзамены, 131 глава и 242 сноски. Сборка через сценарий `scripts/build_iman_v15.py`. Визуальный результат на реальном телефоне ещё требует проверки.
