# Книга Имана v0.14

Новая исходная работа: самостоятельный фон для большой цитатной карточки и четыре отдельно созданных 3D-значка с прозрачностью. Все семь вращающихся цитат побайтово проверяются на наличие в оригинальных блоках встроенного текста `book.json`; не изменяется ни одна строка книги. При новом создании главного экрана цитата последовательно меняется, дополнительно доступна кнопка ручного переключения и точный переход к главе/блоку.

Четыре карточки разделов уплотнены, используют прозрачные изображения (не квадратные подложки). Блок озвучки оформлен в тёплой палитре; сохранены RuVoice, скорость, пауза, остановка, ошибка и переход к настройкам движка. Убран рекламный текст установки. Прогресс главы без отдельной заливки/Surface, максимально компактный, общий фон страницы виден сквозь него. Android/Kotlin/Compose и существующий 5-кнопочный нижний навбар не менялись.

Текст книги, 131 глава, 242 сноски и 524 задания неизменны. Release подписывается временным ключом CI; обновление поверх прошлой APK не гарантировано, тестовый applicationIdSuffix = `.preview14`. Не объявлять гарантированную визуальную точность без скриншотов с устройства.
